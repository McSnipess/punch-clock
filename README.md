# Punch Clock

A free, mobile-friendly punch clock for GitHub Pages.

## Features
- One button to clock in and clock out
- Uses your device's current local date and time
- Saves shifts in browser storage on your device
- Live shift timer, weekly and monthly totals
- Dark and light themes
- Add previous shifts manually
- Edit or delete saved shifts
- Optional notes for each shift
- CSV export
- Basic offline support after the first load

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `punch-clock` (or any name you like).
2. Upload `index.html`, `manifest.json`, `sw.js`, and this `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then press **Save**.
6. Wait for GitHub to publish it. The URL will look like `https://YOUR-USERNAME.github.io/punch-clock/`.

## Add it to iPhone Home Screen
1. Open the published GitHub Pages URL in **Safari**.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Name it Punch Clock and tap **Add**.

## Important
- Your shift records are saved in this browser on this device, not synced to GitHub or other devices.
- Avoid clearing Safari website data unless you have exported your CSV backup.
- Keep your phone's date, time, and time zone set correctly. The app uses the device's local clock.
- This is a personal tracker, not an official payroll timekeeping system.
